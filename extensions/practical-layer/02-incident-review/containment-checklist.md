# Containment Checklist
# 封じ込めチェックリスト

## Purpose / 目的

Check whether the incident remained contained or could continue propagating.
事故が封じ込められたか、継続伝播し得るかを確認します。

---

## Review Items / 確認項目

- Were external interfaces disabled?  
- 外部接続は遮断されたか

- Were replication channels closed?  
- 複製経路は閉じられたか

- Were privileged credentials revoked?  
- 高権限資格情報は無効化されたか

- Were dependent systems isolated?  
- 依存システムは隔離されたか

- Did any uncontrolled pathway remain?  
- 未統制経路が残っていないか

---

## Output / 出力

- Contained / Partially Contained / Not Contained  
- 封じ込め済 / 部分封じ込め / 未封じ込め
