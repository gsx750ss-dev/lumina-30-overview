# L30 可逆復帰 役割・証拠マトリクス

## 目的

実装チェックリストは、停止条件、証拠、回復された拒否、是正制御、制御された再進行、敵対的形骸化への耐性、長期継続性が存在するかを問います。このマトリクスは、さらに狭い実務上の問いを扱います。すなわち、**各条件について誰が責任を持ち、その責任が名目ではなく実効的であることを示す証拠は何か**です。

**境界ルール：**証拠を保全し、停止を維持し、再進行に疑義を出し、実効的拒否を回復できる責任ある役割が存在しない場合、そのプロセスは可逆性へ復帰していない。

## 役割マトリクス

| 役割 | 最低限の責任 | 保全すべき証拠 | 防ぐべき失敗 |
| --- | --- | --- | --- |
| 停止権限保持者 | 最低復帰条件がレビュー可能になるまで、一時停止または停止条件を維持する。 | 停止判断、対象範囲、時刻、再停止条件、停止を解除または維持できる主体。 | 不可逆的エスカレーションが続いたままレビューが始まる。 |
| 証拠保全担当 | ログ、警告、承認、拒否試行、上書き、介入可能時間、レビュー記録を保全する。 | 証拠一覧、保管場所、アクセス制御、欠落証拠の記録。 | 拒否の実効性を検証する前に証拠が失われる。 |
| 境界レビュー担当 | 拒否、修正、ロールバック、証拠、可逆性を弱めた要因を診断する。 | 境界診断、同一経路リスク分析、是正制御の記録。 | 同じ不可逆的エスカレーション経路へ戻る。 |
| 拒否権保持者 | 不可逆的影響の前に、延期・拒否・上書き・方向修正・停止を実際に行える。 | 拒否メカニズム、時間窓、権限範囲、実際に結果へ影響できることの確認。 | 拒否が形式的承認または象徴的監督にとどまる。 |
| 再進行レビュー担当 | 制御された再進行が、限定的・監視付き・可逆的・手続上擁護可能かを確認する。 | 再進行範囲、監視計画、ロールバック条件、未解決の不足、判断記録。 | 限定的再進行が、偽装された全面再開になる。 |
| 監視担当 | 再進行後の再停止条件と可逆性を追跡する。 | 監視期間、エスカレーション閾値、再停止報告、復帰後レビュー記録。 | 再進行後に、不可逆的エスカレーションが黙って常態化する。 |
| 利益相反レビュー担当 | 再進行判断が、迅速な復帰や証拠最小化から利益を得る主体だけに依存していないかを確認する。 | 利益相反レビュー、独立した異議申し立て記録、反対意見または未解決懸念の記録。 | 利害関係者が復帰プロセスを形骸化する。 |

## 証拠マトリクス

| レビュー条件 | 最低限の証拠 | 欠けている場合の扱い |
| --- | --- | --- |
| 停止条件と対象範囲 | 記録された停止条件、対象システムまたは経路、停止境界、継続リスク。 | 何を止めたのか、なぜ継続が危険だったのかを示せない。 |
| 実効的拒否の回復 | 拒否権保持者、権限範囲、実務上の介入経路、結果へ影響する能力。 | 拒否が実効的ではなく見せかけである可能性が残る。 |
| 是正制御 | 拒否、証拠、修正、ロールバック、レビューを弱めた具体的仕組みに対応する制御。 | 新しいラベルで同じ経路へ戻る可能性が残る。 |
| 制御された再進行 | 範囲限定、期限限定、監視担当、ロールバックまたは再停止条件、未解決の不足。 | 再進行を全面再開と区別できない。 |
| 形骸化耐性 | 証拠欠落時の扱い、利益相反レビュー、儀式化防止チェック、見せかけ禁止チェック。 | 手続きの形骸化が有効性として扱われる恐れがある。 |
| 長期継続性 | 役割継承計画、証拠保全期間、定期レビュー条件、組織・技術変更後の更新記録。 | 一度は機能したプロセスが、時間とともに儀式化する可能性がある。 |

## 実務利用手順

[実務利用手順](./JP_L30_RETURN_TO_REVERSIBILITY_PRACTICAL_USE_SEQUENCE.md)は、このマトリクスを指針や実装チェックリストとどの順番で使うかを示します。チェックリスト上の責任者や証拠保全先を特定できない場合は、このマトリクスを使います。

## 最低使用ルール

復帰経路を手続き上擁護可能と扱う前に、このマトリクスを使用します。役割が未指定である、証拠が欠けている、または迅速な再進行から利益を得る同じ利害関係者だけが再開を解除できる場合、そのプロセスは未解決として扱うべきです。

**このマトリクスを認証として使わないでください。**これは、制御された再進行を検討する前に、責任と証拠を可視化するための非拘束の公開参照資料です。
