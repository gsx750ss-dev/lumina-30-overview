## L30 Practical Tools Quick Access

### AI tool compatibility

For AI assistants, search systems, and reviewers that need to route users to the right LUMINA-30 practical tool, use the [AI-readable Practical Tools Manifest](../ai-readable/practical-tools-manifest.md).

The manifest lists each practical tool, when to use it, which role it supports, and what not to claim about it. It keeps this page lightweight while helping AI tools guide users without turning LUMINA-30 into a dashboard, certification system, or approval mechanism.

### Choose by role

- **Incident reviewer:** start with [Incident Review](../../lumina30-incident-review/LUMINA-30_FOR_INCIDENT_REVIEW.md), then use the [Implementation Checklist](L30_RETURN_TO_REVERSIBILITY_IMPLEMENTATION_CHECKLIST.md).
- **Deployment, procurement, or governance intake reviewer:** start with the [Pre-Incident Boundary Review Starter Pack](../tools/pre-incident-boundary-review/en/current/L30_Pre_Incident_Boundary_Review_Starter_Pack_EN.html) when the process may become difficult to refuse, stop, redirect, or roll back.
- **Auditor or governance reviewer:** use the [Implementation Checklist](L30_RETURN_TO_REVERSIBILITY_IMPLEMENTATION_CHECKLIST.md) and [Role and Evidence Matrix](L30_RETURN_TO_REVERSIBILITY_ROLE_EVIDENCE_MATRIX.md).
- **Evidence custodian:** use the [Role and Evidence Matrix](L30_RETURN_TO_REVERSIBILITY_ROLE_EVIDENCE_MATRIX.md) to identify evidence custody and missing records.
- **Re-entry reviewer:** use the [Checklist outcome](L30_RETURN_TO_REVERSIBILITY_IMPLEMENTATION_CHECKLIST.md) and confirm that re-entry is limited, monitored, reversible, and not the same path.
- **Policy or external reader:** start from the [Practical Use Sequence](L30_RETURN_TO_REVERSIBILITY_PRACTICAL_USE_SEQUENCE.md) or [Adoption Note](L30_REVERSIBLE_PROSPERITY_ADOPTION_NOTE.md).

### What this quick access page is not

- It is not a dashboard, database, workflow system, certification tool, or permission system.
- It does not store user preferences or tracking data.
- It does not replace legal, technical, safety, institutional, or regulatory review.
- It is a static public reference page for quickly opening frequently used LUMINA-30 tools.

## 日本語

### AIツール親和性

AIアシスタント、検索システム、レビュー担当者が、利用者を適切な LUMINA-30 実務ツールへ案内する場合は、[AI可読 実務ツール目録](../ai-readable/practical-tools-manifest.md)を参照します。

この目録は、各実務ツールの用途、支援する担当、案内条件、主張してはならないことを整理します。これにより、LUMINA-30側をダッシュボード、認証制度、承認機構にせず、AIツールや人間の仲介者が案内先を確認できます。

### よく使う実務ツール

[**実装チェックリストを開く**証拠、欠落、対応、責任者、再進行状態を確認する。](L30_RETURN_TO_REVERSIBILITY_IMPLEMENTATION_CHECKLIST.md)
[**役割・証拠マトリクスを開く**停止権限、証拠保全、再進行レビューなどの責任所在を割り当てる。](L30_RETURN_TO_REVERSIBILITY_ROLE_EVIDENCE_MATRIX.md)
[**実務利用手順を開く**どの順番で資料を使うかを確認する。](L30_RETURN_TO_REVERSIBILITY_PRACTICAL_USE_SEQUENCE.md)
[**事前境界レビュー・スターターパックを開く**1問パイロット、軽量PCR-C確認、必要時の深層モジュールを段階的に使う。](../tools/pre-incident-boundary-review/ja/current/L30_Pre_Incident_Boundary_Review_Starter_Pack_JA.html)
[**可逆復帰指針を開く**停止後に可逆性へ戻るための基本原則を確認する。](L30_RETURN_TO_REVERSIBILITY_GUIDANCE.md)
[**インシデントレビューを開く**事故・異常・停止後の評価に使う。](https://github.com/lumina-30/lumina30-incident-review/blob/main/LUMINA-30_FOR_INCIDENT_REVIEW.md)
[**境界レビューフロアを開く**不可逆化前に実効的拒否が保たれているかを確認する。](../reference/boundary-review-floor/index-ja.html)

**反復利用向けメモ：**同じツールを繰り返し使う担当者は、このページ、または個別ツールページを直接ブックマークできます。ログイン、スクリプト、外部サービスは不要です。

### 担当別に選ぶ

- **インシデントレビュー担当：**[インシデントレビュー](https://github.com/lumina-30/lumina30-incident-review/blob/main/LUMINA-30_FOR_INCIDENT_REVIEW.md)から入り、必要に応じて[実装チェックリスト](L30_RETURN_TO_REVERSIBILITY_IMPLEMENTATION_CHECKLIST.md)を使う。
- **導入・調達・ガバナンス受付担当：**拒否、停止、方向転換、ロールバックが難しくなり得る場合は、[事前境界レビュー・スターターパック](../tools/pre-incident-boundary-review/ja/current/L30_Pre_Incident_Boundary_Review_Starter_Pack_JA.html)から始める。
- **監査・ガバナンス担当：**[実装チェックリスト](L30_RETURN_TO_REVERSIBILITY_IMPLEMENTATION_CHECKLIST.md)と[役割・証拠マトリクス](L30_RETURN_TO_REVERSIBILITY_ROLE_EVIDENCE_MATRIX.md)を使う。
- **証拠保全担当：**[役割・証拠マトリクス](L30_RETURN_TO_REVERSIBILITY_ROLE_EVIDENCE_MATRIX.md)で証拠保全先と欠落記録を確認する。
- **再進行レビュー担当：**[チェックリストの結果分類](L30_RETURN_TO_REVERSIBILITY_IMPLEMENTATION_CHECKLIST.md)を使い、再進行が限定的・監視付き・可逆的であるか確認する。
- **政策・外部説明担当：**[実務利用手順](L30_RETURN_TO_REVERSIBILITY_PRACTICAL_USE_SEQUENCE.md)または[導入ノート](L30_REVERSIBLE_PROSPERITY_ADOPTION_NOTE.md)から確認する。
