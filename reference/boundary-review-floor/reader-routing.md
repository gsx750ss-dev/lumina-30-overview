# Reception ｜ 受付

This page routes readers to the right room in the Boundary Review Floor.

このページは、境界レビューフロア内で自分に合う部屋を選ぶための受付です。

## Minimal path ｜ 最短経路

If you only have two minutes, use the beginner route. It is enough to carry the core question, but not enough to claim full understanding of LUMINA-30.

2分しかない場合は、初級ルートを使ってください。中核質問を持ち帰るには十分ですが、LUMINA-30全体を完全理解したと主張するためのものではありません。

1. [A Room: Boundary Understanding](./formal-oversight-effective-refusal.md) ｜ [Aルーム：境界理解室](./formal-oversight-effective-refusal.md)  
2. [G Room: Walkthrough](./walkthrough-room.md) ｜ [Gルーム：読み替え例の部屋](./walkthrough-room.md)  
3. [C Room: Share](./shareable-boundary-question.md) ｜ [Cルーム：持ち帰りの部屋](./shareable-boundary-question.md)  
4. [F Room: Review Lens Check — Level 1](./review-lens-check.md#level-1) ｜ [Fルーム：レビュー視点チェック — Level 1](./review-lens-check.md#level-1)

## Deeper paths ｜ より深いルート

- **Level 2 — Core Reading Check**: use this when you want to apply the boundary question as a basic review lens.  
  **Level 2 — 中核読了チェック**：境界質問を基本的なレビュー視点として使いたい場合に使ってください。

- **Level 3 — Applied / Advanced Check**: use this when you need audit, governance, incident-review, or research-facing use.  
  **Level 3 — 実務・上級チェック**：監査、ガバナンス、事故後レビュー、研究寄りの利用が必要な場合に使ってください。

## External-use path ｜ 外部制度・団体接続ルート

If you work with an external governance, standards, incident-response, or human-oversight context, start with D Room. Use F Room Level 3 only after you need to check whether you can apply the review lens in that external context.

外部ガバナンス、標準化、事故対応、人間監督文脈で扱う場合は、Dルームから始めてください。その外部文脈でレビュー視点を使えるか確認する必要がある場合のみ、Fルーム Level 3 を使用してください。

- [D Room: External-use notes](./connection-to-existing-ai-governance.md#external-use-notes) ｜ [Dルーム：外部制度・団体接続メモ](./connection-to-existing-ai-governance.md#external-use-notes)
- [F Room: Review Lens Check — Level 3](./review-lens-check.md#level-3) ｜ [Fルーム：レビュー視点チェック — Level 3](./review-lens-check.md#level-3)

## If you are unsure ｜ 迷った場合

Start with this sentence:

まず、この一文から始めてください。

> LUMINA-30 does not ask whether oversight existed; it asks whether refusal remained effective before irreversibility.
>
> LUMINA-30は、監督が存在したかではなく、不可逆化前に拒否がなお実効的だったかを問います。
