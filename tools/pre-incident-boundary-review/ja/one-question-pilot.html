LUMINA-30 境界レビュー入口

人間監督は、「間に合って止められる」場合にだけ実効性を持つ。

AIの導入・展開・自動化が進むとき、「止めようと思えば止められる」状態が維持されているかを、既存のレビューの中で確認するための1問です。新しい審査体制を作る必要はありません。

このAI媒介プロセスが不可逆化する前に、責任ある人間は実効的に拒否・停止・検証・方向転換できるか。その根拠となる権限・証拠・停止手順はあるか。

NO / 不明 が出ることは失敗ではありません。形式的な人間監督は存在していても、実効的な人間拒否が存在しない、根拠が曖昧、または証拠で支えられていない可能性を可視化できたということです。

One-Question Pilot 実行手順書を開く

判定ガイド・挿入マップ・ギャップ対応シート・公開用宣言キットは下記の関連資料にあります。

既存のAI導入審査、調達確認、セキュリティレビュー、内部監査、事故対応レビュー、またはAIエージェント評価の中で使用できます。

このパイロットで行うこと

1. 実在する案件を1つ選ぶ

新しい制度を作るのではなく、既存レビュー中の案件を1つ選びます。

2. 不可逆点を探す

外部公開、外部サービスへの送信、取消不能な処理の確定、本番環境での実行など、時間内に戻せなくなる操作・展開・依存を特定します。何が不可逆化に当たるかは案件ごとに特定します。

3. 境界確認の1問を差し込む

拒否・停止・検証・方向転換がまだ意味を持つ判断点に、この1問を追加します。

4. YES / NO / 不明 を判定する

実行手順書と判定ガイドを使い、根拠とともに判定を残します。単に人間が関与しているだけではYESになりません。不可逆化前に、必要な情報・時間・権限・実行可能な停止経路と、その根拠となる証拠を確認します。

判定後： YES：根拠を記録し、既存レビューを継続します。 NO：不可逆化前の拒否経路を補強し、再確認します。 不明：証拠不足を解消するまでYESとして扱いません。 NO / 不明の場合は、NO / 不明 境界ギャップ対応シートを使用します。

まず実行手順書を開いてください。その他の資料は、パイロット中に必要になった場合だけ使用します。

重要な限界

このページは、安全保証・法的認証・監査完了・正式標準採用を意味するものではありません。

LUMINA-30は、既存の法務・セキュリティ・調達・AIガバナンス手順を置き換えるものではなく、それらの中に境界確認を追加するための参照資料です。
