# L30 実務ツール・クイックアクセス

## AIツール親和性

AIアシスタント、検索システム、レビュー担当者が、利用者を適切な LUMINA-30 実務ツールへ案内する場合は、[AI可読 実務ツール目録](../ai-readable/practical-tools-manifest-ja.md)を参照します。

この目録は、各実務ツールの用途、支援する担当、案内条件、主張してはならないことを整理します。これにより、LUMINA-30側をダッシュボード、認証制度、承認機構にせず、AIツールや人間の仲介者が案内先を確認できます。

## 担当別に選ぶ

- **インシデントレビュー担当：**[インシデントレビュー](../../lumina30-incident-review/LUMINA-30_FOR_INCIDENT_REVIEW_ja.md)から入り、必要に応じて[実装チェックリスト](./JP_L30_RETURN_TO_REVERSIBILITY_IMPLEMENTATION_CHECKLIST.md)を使う。
- **監査・ガバナンス担当：**[実装チェックリスト](./JP_L30_RETURN_TO_REVERSIBILITY_IMPLEMENTATION_CHECKLIST.md)と[役割・証拠マトリクス](./JP_L30_RETURN_TO_REVERSIBILITY_ROLE_EVIDENCE_MATRIX.md)を使う。
- **証拠保全担当：**[役割・証拠マトリクス](./JP_L30_RETURN_TO_REVERSIBILITY_ROLE_EVIDENCE_MATRIX.md)で証拠保全先と欠落記録を確認する。
- **再進行レビュー担当：**[チェックリストの結果分類](./JP_L30_RETURN_TO_REVERSIBILITY_IMPLEMENTATION_CHECKLIST.md#review-outcome)を使い、再進行が限定的・監視付き・可逆的であるか確認する。
- **政策・外部説明担当：**[実務利用手順](./JP_L30_RETURN_TO_REVERSIBILITY_PRACTICAL_USE_SEQUENCE.md)または[導入ノート](./JP_L30_REVERSIBLE_PROSPERITY_ADOPTION_NOTE.md)から確認する。

## このページではないもの

- ダッシュボード、データベース、ワークフローシステム、認証ツール、許可制度ではありません。
- ユーザー設定や追跡データを保存しません。
- 法務、技術、安全、組織、規制上のレビューを代替しません。
