# Restart Approval Review
# 再起動承認レビュー

## Purpose / 目的

Assess whether restart or redeployment should be blocked pending review.
レビュー完了前に再起動・再展開を止めるべきかを確認します。

---

## Review Items / 確認項目

- Were root causes identified?  
- 根本原因は特定されたか

- Were safeguards added before restart?  
- 再起動前に保護措置が追加されたか

- Was independent review completed?  
- 独立レビューは完了したか

- Would restart recreate the same exposure?  
- 再起動で同じ暴露が再現されないか

- Was restart authority separated from incident owners?  
- 再起動承認権限は事故当事者から分離されていたか

---

## Output / 出力

- Approve / Delay / Reject  
- 承認 / 保留 / 却下
