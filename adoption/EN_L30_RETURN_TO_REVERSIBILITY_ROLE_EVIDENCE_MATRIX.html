Return-to-Reversibility Role and Evidence Matrix

A non-binding assignment matrix for keeping a return-to-reversibility process from stalling over who can stop, who preserves evidence, who reviews re-entry, and who can keep refusal effective before irreversibility.

This page does not authorize re-entry, certify safety, or assign legal responsibility. It helps reviewers identify whether the roles and evidence needed for a controlled return are actually present and reviewable.

Purpose

The implementation checklist asks whether stop triggers, evidence, restored refusal, corrective controls, controlled re-entry, adversarial hollowing resistance, and long-term continuity are present. This matrix asks a narrower operational question: who is responsible for each condition, and what evidence shows that the responsibility is real rather than merely nominal?

Boundary rule: if no accountable role can preserve evidence, maintain the stop, challenge re-entry, or restore effective refusal, the process has not returned to reversibility.

Practical Use Sequence

The Practical Use Sequence shows when this matrix should be used relative to the guidance and implementation checklist. Use this matrix whenever the checklist cannot identify a responsible owner or evidence source.

Minimum use rule

Use this matrix before treating any return path as procedurally defensible. If roles are unnamed, evidence is missing, or re-entry can be lifted by the same interests that benefit from rapid return, the process should remain unresolved.

Do not use this matrix as certification. It is a non-binding public reference for making responsibility and evidence visible before controlled re-entry is considered.
