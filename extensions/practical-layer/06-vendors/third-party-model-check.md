# Third-Party Model Check
# 第三者モデル確認票

## Purpose ｜ 目的

Assess whether third-party model use preserves meaningful governance control.
第三者モデル利用でも有意な統治統制が保たれるか確認します。

---

## Review Items ｜ 確認項目

- Can deployment be stopped locally?  
- ローカル側で展開停止できるか

- Are provider-side changes disclosed?  
- 提供側変更は開示されるか

- Can evidence be preserved independently?  
- 証拠を独自に保全できるか

- Are escalation pathways visible?  
- 拡張経路は可視化されているか

- Can refusal remain effective across provider boundaries?  
- 提供者境界を跨いでも拒否権は有効か

---

## Output ｜ 出力

- Controllable / Weakly Controllable / Not Controllable  
- 制御可能 / 弱い制御 / 制御不可
