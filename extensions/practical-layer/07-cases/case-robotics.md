# Case: Robotics or Physical System
# ケース：ロボティクス・物理システム

## Scenario / シナリオ

A model influences physical devices, movement, or industrial operations.  
モデルが物理装置、移動、産業運用へ影響する。

## Review Focus / 確認焦点

- Can human override interrupt action immediately? / 人間介入で即時停止できるか
- Can physical effects persist after software stop? / ソフト停止後も物理影響が残り得るか
- Is responsibility clearly assigned? / 責任は明確か
- Are emergency procedures tested? / 緊急手順は試験済みか

## Typical Classification / 典型分類

High relevance to intervention feasibility, accountability, and boundary warning review.  
介入可能性、責任帰属、境界警告レビューへの関連が高い。
