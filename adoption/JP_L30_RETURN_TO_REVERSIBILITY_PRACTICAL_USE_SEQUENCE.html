いつ使うか

境界懸念、拒否の弱体化、証拠欠落、一時停止、または不可逆的エスカレーションへの移行の兆候が見つかった後、レビュー担当者が何から確認すべきかを整理したい場合に使います。

最低原則：何を止めたか、どの証拠を保全したか、誰が拒否または停止を維持できるか、何を変更したか、再進行がなぜ限定的・監視付き・可逆的なのかを示せない限り、復帰を手続上擁護可能とは扱わない。

実務利用の順番

段階使う場面主なLUMINA-30参照資料期待される出力
1. 境界懸念を特定する実効的拒否、レビュー可能性、修正、ロールバック、証拠が弱まり始めている可能性がある。境界レビューフロア / インシデントレビュー境界問いとレビュー開始条件を特定する。
2. 常態化する前に止める・一時停止する継続すると不可逆的エスカレーションが常態化したり、証拠が失われたりする可能性がある。可逆復帰指針停止範囲、停止条件、証拠保全の必要性を記録する。
3. 復帰経路を確認項目へ落とす一般原則ではなく、具体的な確認項目が必要である。実装チェックリスト証拠、欠落、対応、責任者、再進行状態を記録する。
4. 責任所在と証拠保全を割り当てる誰が停止を維持し、証拠を保全し、再進行に異議を唱え、再停止条件を監視するのかが不明確である。役割・証拠マトリクス停止権限保持者、証拠保全担当、境界レビュー担当、拒否権保持者、再進行レビュー担当、監視担当、利益相反レビュー担当を特定する。
5. 再進行状態を判断する停止継続、限定的な制御された再進行、監視継続のどれに該当するかを判断する必要がある。チェックリストの結果分類再進行しない / 限定的な制御された再進行のみ / 監視を継続する。
6. 可逆性を長期的に維持する初回レビュー後に、人員、システム、制度、誘因が変化する。長期継続性 と 形骸化防止定期レビュー、再停止条件、役割継承、証拠保全を維持する。

最小実務手順

  1. 境界懸念と停止条件を特定する。
  2. 証拠が失われる前に保全する。
  3. 実装チェックリストで、証拠、欠落、対応、責任者、再進行状態を記録する。
  4. 役割・証拠マトリクスで、責任者と証拠保全先を明確にする。
  5. 制御された再進行条件がレビュー可能でない限り、再進行しない。
  6. 復帰後監視と再停止条件を維持する。

迷った場合

どこから始めるべきか迷う場合は、まず 実装チェックリスト を使います。必要項目の責任者や証拠保全先が特定できない場合は、直ちに 役割・証拠マトリクス を使います。

境界ルール：実際の拒否と見せかけの拒否、実際の可逆性と見せかけの可逆性、実際のレビューと儀式的レビューを区別できないプロセスは、可逆性へ復帰していない。
