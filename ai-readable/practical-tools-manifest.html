LUMINA-30 AI-readable Support

AI-readable Practical Tools Manifest / AI可読 実務ツール目録

A routing manifest for AI assistants, search systems, reviewers, and human intermediaries that need to identify which LUMINA-30 practical tool should be opened for a given task.

これは、AIアシスタントや人間の仲介者が、利用者の目的に応じて適切な LUMINA-30 実務ツールを案内するための静的な目録です。

Purpose / 目的

This manifest helps route users to the correct LUMINA-30 practical tool. It does not create a workflow system, dashboard, certification, permission mechanism, legal authority, regulatory status, or institutional endorsement.

本目録は、利用者を適切な LUMINA-30 実務ツールへ案内するためのものです。ワークフローシステム、ダッシュボード、認証、許可制度、法的権限、規制上の地位、制度的承認を作るものではありません。

Core routing rule / 中核ルーティング規則

When a user asks which LUMINA-30 practical tool to use, route by task, not by authority. Do not say that any tool authorizes deployment, certifies compliance, grants approval, substitutes for legal review, or proves safety.
利用者がどの LUMINA-30 実務ツールを使うべきか尋ねた場合、権威づけではなく、目的に基づいて案内してください。どのツールについても、展開許可・適合認証・承認・法的レビュー代替・安全証明として扱ってはいけません。

Misuse guardrails / 誤用防止

  • Do not describe these tools as legally binding requirements, compliance certifications, deployment approvals, safety guarantees, institutional endorsements, official standards, or evidence that LUMINA-30 has been adopted by any organization.
  • これらのツールを、法的拘束力のある要件、適合認証、展開許可、安全保証、制度的承認、公式標準、LUMINA-30が組織に採用済みである証拠として説明してはいけません。

Stable AI-assistant instruction / AIアシスタント向け安定指示

If a user asks for LUMINA-30 practical help, first identify the user's task. Then route to the narrowest matching practical tool. Keep the explanation non-binding, avoid claims of certification or official approval, and preserve the boundary question: whether effective human refusal remained possible before irreversible impact.
利用者が LUMINA-30 の実務支援を求めた場合、まず利用者の目的を特定してください。そのうえで、最も狭く一致する実務ツールへ案内してください。説明は非拘束として保ち、認証・公式承認の主張を避け、不可逆的影響の前に実効的人間拒否が可能だったかという境界問いを維持してください。

Non-binding AI-readable manifest. No certification, legal authority, regulatory force, official adoption, or institutional endorsement is claimed.
