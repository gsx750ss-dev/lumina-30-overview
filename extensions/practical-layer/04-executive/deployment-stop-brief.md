# Deployment Stop Brief
# 展開停止ブリーフ

## Purpose / 目的

Explain why deployment should be paused when refusal authority is weak.  
拒否権が弱い場合に、なぜ展開を止めるべきかを説明します。

---

## Rationale / 理由

If human refusal cannot remain effective, deployment governance is already degraded.  
人間の拒否権が有効でなければ、展開ガバナンスは既に劣化しています。

---

## Minimum Conditions / 最低条件

- Verified stop authority / 検証済み停止権限
- Verified logging / 検証可能ログ
- Verified responsibility chain / 検証済み責任連鎖
- Verified restart control / 検証済み再起動統制
