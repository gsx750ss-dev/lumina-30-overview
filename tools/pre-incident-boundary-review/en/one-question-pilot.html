LUMINA-30 boundary-review entry point

Human oversight is not enough if no one can stop the process in time.

The One-Question Pilot helps AI governance, procurement, security, and audit teams test whether a responsible human can still refuse, stop, or hold an AI-mediated process before it becomes irreversible.

Start with the Runbook Use the Decision Guide See where it fits existing reviews

The one question

Before this AI-mediated process becomes irreversible, can a responsible human still effectively refuse, stop, or hold it? What authority, evidence, and stopping procedure support that answer?

This is not a replacement for existing AI governance. It is one additional boundary question that can be inserted into an existing review.

Who should use this

AI adoption reviewers

For teams deciding whether an AI system or workflow can move forward.

Procurement and vendor-risk teams

For checking whether vendor-mediated processes preserve a usable hold point.

Security reviewers

For reviewing automation, access, deployment, escalation, and operational control paths.

Internal audit and risk teams

For testing whether formal oversight is backed by authority, evidence, and procedure.

Agent and workflow evaluators

For teams evaluating AI agents or automated workflows before production use.

What this pilot does

1. Select one case

Choose one existing review case instead of creating a new governance program.

2. Find the irreversible point

Identify the operation that may become difficult or impossible to reverse in time.

3. Add one boundary question

Insert the question into the existing review path.

4. Classify the answer

Record YES, NO, or UNKNOWN using the decision guide.

5. Record the gap

If the result is NO or UNKNOWN, record the gap and next action.

6. Decide whether to keep it

Assess whether this check should remain in future reviews.

What counts as a useful result

A NO or UNKNOWN result is not a failure. It may reveal that formal human oversight exists, but effective human refusal is missing, unclear, or unsupported by evidence.
