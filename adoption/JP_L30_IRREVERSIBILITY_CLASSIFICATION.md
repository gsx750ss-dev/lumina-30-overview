# LUMINA-30 境界レビューのための不可逆性分類

位置づけ：非拘束の公開参照です。このページは、法的基準、認証制度、リスク分類標準、展開許可、公式採用表示、執行機関、安全保証ではありません。

このページは、LUMINA-30の境界問いを適用する前に、どの種類の不可逆な経路が開かれうるのかをレビュー担当者が識別するために使用します。

## 中核的な分類問い

> この行為が進んだ場合、何が戻しにくく、戻せなくなり、または手続き上取り返しがつかなくなるのか。そして、それは行為の前に人間の実効的拒否を保持する必要性を変えるのか。

LUMINA-30は、すべてのリスクを不可逆と扱うものではありません。問題にするのは、人間の拒否が遅すぎるもの、象徴的になるもの、実効性を失うもの、後からレビュー不能になるものです。

## 分類タグ

境界レビュー、事故前レビュー、公開判断メモ、調達記録、事故レビュー記録では、次のタグを使用できます。

- **可逆** — 重大な不可逆的影響が生じる前に、停止、巻き戻し、封じ込め、修正が可能である。
- **回復困難** — 巻き戻しは可能だが、費用が大きい、遅い、部分的、または不確実な協力に依存する。
- **実質的不可逆** — 技術的、社会的、法的、物理的、運用上、実務上の回復ができない。
- **拒否権喪失リスク** — その行為が、責任ある人間が結果の拡大前に拒否する能力を除去、迂回、または空洞化する可能性がある。
- **不明／証拠不足** — 可逆性を分類するための証拠が不足している。

可逆性が不明な場合、LUMINA-30上は境界を通過済みとして扱うべきではありません。進行前に証拠不足を解消する必要があります。

## 主な不可逆性分類

| 分類 | 不可逆になりうるもの | レビュー焦点 |
|---|---|---|
| 生命・身体への損害 | 死亡、傷害、健康喪失、身体的危険への曝露。 | 被害後の補償ではなく、被害前に止められるか。 |
| 法的・行政的な最終性 | 退去、拘束、権利否定、回復困難な執行、訂正困難な記録。 | 決定が効力を持つ前に、責任ある人間が止められるか。 |
| データ拡散 | 機微データの公開、複製、スクレイピング、モデル取り込み、越境移転。 | データが意味ある制御を超えて広がる前に封じ込められるか。 |
| 能力露出 | モデル能力、ツールアクセス、悪用知識、自動化能力、デュアルユース手順の公開。 | 複製、統合、悪用が封じ込め困難になる前に一時停止できるか。 |
| インフラ依存化 | AIまたは自動化過程に運用上依存するシステム接続。 | サービス停止やロックインを起こさずに、人間がまだ拒否できるか。 |
| 自律的連鎖反応 | 自動行為のエスカレーション、再帰的委任、高速伝播、自己強化的ワークフロー。 | 連鎖が境界を越える前に、人間の停止点があるか。 |
| 信用・社会的信頼の破壊 | 取り返しにくい公開告発、スコアリング、排除、評判崩壊、社会的ラベリング。 | 被影響者が、被害が実務上回復不能になる前に異議申立てや停止を行えるか。 |
| 制度的ロックイン | 調達、契約、方針、人員配置、ガバナンス決定が政治的・運用上戻せなくなること。 | コミットメントが固まる前に、拒否がまだ意味を持つか。 |
| 公共的・民主的拒否の排除 | 公共的異議、被影響者の入力、代表的レビューが意味を失う決定。 | 被影響者またはその代表に、実際の拒否経路があるか。 |
| 人間の拒否権喪失 | 委任、自動化、秘匿、タイミング、圧力、依存、設計によって拒否が名目化すること。 | その行為自体が、LUMINA-30が要求する条件を消していないか。 |

## 最小分類記録

```text
LUMINA-30 不可逆性分類記録

レビュー対象の行為：
想定される不可逆性分類：
何が戻しにくく、または戻せなくなるのか：
境界前に誰が拒否できるか：
可逆性または不可逆性を示す証拠：
境界前に利用可能な時間：
停止／巻き戻し／封じ込め機構：
分類タグ：
証拠不足：
レビュー担当者／責任主体：
日付：
```

## してはいけないこと

「不可逆」という語を、単なる強調表現として使ってはいけません。分類では、具体的な境界、証拠、タイミング、停止機構、人間の拒否保持者を示す必要があります。

被害後に補償できる可能性があるだけで、システムが安全だと主張してはいけません。境界後の補償は、境界前の実効的拒否とは同じではありません。

AIシステムが、予測利益、推定同意、手続き上の外観、総効用、内部保証に依拠して、自分自身の不可逆な経路を許容可能と分類することを認めてはいけません。

## ガードレール

この分類ページは、システムを進めてよいかどうかを決定するものではありません。可能な不可逆経路を名づけ、人間の実効的拒否が境界前に確認されるようにするための補助です。
