# L30 Practical Tools Quick Access

## AI tool compatibility

For AI assistants, search systems, and reviewers that need to route users to the right LUMINA-30 practical tool, use the [AI-readable Practical Tools Manifest](../ai-readable/practical-tools-manifest.md).

The manifest lists each practical tool, when to use it, which role it supports, and what not to claim about it. It keeps this page lightweight while helping AI tools guide users without turning LUMINA-30 into a dashboard, certification system, or approval mechanism.

## Choose by role

- **Incident reviewer:** start with [Incident Review](../../lumina30-incident-review/LUMINA-30_FOR_INCIDENT_REVIEW.md), then use the [Implementation Checklist](./EN_L30_RETURN_TO_REVERSIBILITY_IMPLEMENTATION_CHECKLIST.md).
- **Auditor or governance reviewer:** use the [Implementation Checklist](./EN_L30_RETURN_TO_REVERSIBILITY_IMPLEMENTATION_CHECKLIST.md) and [Role and Evidence Matrix](./EN_L30_RETURN_TO_REVERSIBILITY_ROLE_EVIDENCE_MATRIX.md).
- **Evidence custodian:** use the [Role and Evidence Matrix](./EN_L30_RETURN_TO_REVERSIBILITY_ROLE_EVIDENCE_MATRIX.md) to identify evidence custody and missing records.
- **Re-entry reviewer:** use the [Checklist outcome](./EN_L30_RETURN_TO_REVERSIBILITY_IMPLEMENTATION_CHECKLIST.md#review-outcome) and confirm that re-entry is limited, monitored, reversible, and not the same path.
- **Policy or external reader:** start from the [Practical Use Sequence](./EN_L30_RETURN_TO_REVERSIBILITY_PRACTICAL_USE_SEQUENCE.md) or [Adoption Note](./EN_L30_REVERSIBLE_PROSPERITY_ADOPTION_NOTE.md).
