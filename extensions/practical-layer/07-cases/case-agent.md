# Case: Autonomous Agent Deployment
# ケース：自律エージェント展開

## Scenario ｜ シナリオ

An autonomous agent can browse tools, issue commands, and execute multi-step workflows.  
自律エージェントがツール参照、命令実行、多段ワークフローを行える。

## Review Focus ｜ 確認焦点

- Is stop authority immediate? / 停止権限は即時か
- Can tool access be cut quickly? / ツール接続を迅速に遮断できるか
- Are action logs complete? / 行動ログは完全か
- Can escalation outrun human review? / 拡張が人間審査を上回り得るか

## Typical Classification ｜ 典型分類

High relevance to refusal authority and intervention feasibility.  
拒否権と介入可能性への関連が高い。
