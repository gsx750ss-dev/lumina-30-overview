# Irreversible Risk Screening
# 不可逆リスク審査票

## Purpose / 目的

Screen whether system behavior could create hard-to-reverse external effects.
巻き戻し困難な外部影響を生じ得るか審査します。

---

## Review Items / 確認項目

- Could the system change infrastructure state?  
- インフラ状態を変更し得たか

- Could the system trigger autonomous propagation?  
- 自律的伝播を起こし得たか

- Could human correction occur in time?  
- 人間の是正は間に合うか

- Could losses persist after shutdown?  
- 停止後も影響が残り得るか

- Would evidence decay before review?  
- レビュー前に証拠が劣化しないか

---

## Output / 出力

- Low / Elevated / Critical  
- 低 / 上昇 / 重大
